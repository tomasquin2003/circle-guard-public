## Acceptable HTTP Codes

The following HTTP codes are treated as PASS (service is alive):

200, 201, 204, 301, 302, 400, 401, 403, 404, 405

Codes outside this list, timeouts, connection refused, or container not running = FAIL.

## Limitations

- This suite performs smoke / operational checks only.
- It does NOT cover authenticated flows (JWT, OAuth2, LDAP) because no seed users are provisioned automatically.
- Business-logic scenarios are not yet covered.
- Kafka and Redis are verified indirectly through dependent service health.
- Neo4j health is inferred via promotion-service reachability and container state.
